# راهنمای Epsilon

## اجرای ادیتور

ماژول‌های ES از `file://` بار نمی‌شوند، پس ادیتور باید با سرور محلی باز شود:

```bash
node tools/serve.mjs
```

بعد `http://localhost:8080` را باز کن.

## کلیدهای میانبر

| کلید | کار |
|---|---|
| V / P / R / E | انتخاب، چندضلعی، مستطیل، بیضی |
| Space | پخش و توقف |
| Enter | بستن چندضلعی |
| Delete | حذف نقطه، کلید یا شکل انتخاب‌شده |
| Ctrl+Z / Ctrl+Y | برگشت و تکرار |
| Ctrl+D | کپی شکل |
| Ctrl+S | ذخیرهٔ پروژه |
| Esc | لغو انتخاب |

## ساخت انیمیشن

1. شکل را رسم کن. دوبار کلیک روی لبهٔ شکل انتخاب‌شده نقطهٔ جدید می‌سازد.
2. نشانگر زمان را جابه‌جا کن و شکل یا نقطه‌ها را تغییر بده. کلید خودکار ساخته می‌شود.
3. در تایم‌لاین کلیدها را انتخاب کن. Shift+کلیک یا کشیدن کادر چند کلید را با هم انتخاب می‌کند.
4. در پنل منحنی، منحنی را تنظیم کن یا یکی از پیش‌فرض‌ها را بزن. روی همهٔ کلیدهای انتخاب‌شده اعمال می‌شود.
5. برای منحنی جدا برای هر نقطه، با کلیک روی فلش کنار نام شکل ردیف نقطه‌ها را باز کن.
6. منحنی هر کلید، حرکت از آن کلید تا کلید بعدی را کنترل می‌کند.
7. Depth عمق شکل است. عدد کمتر یعنی نزدیک‌تر، و هنگام تکان خوردن اسباب‌بازی بیشتر جابه‌جا می‌شود.
8. روی شبیه‌ساز بکش تا جلوهٔ تکان را ببینی.

## نسخه‌های رنگی

شکل‌ها به شمارهٔ رنگ وصل‌اند، نه به خود رنگ. هر نسخهٔ رنگی فقط یک پالت جداست و هندسه تکرار نمی‌شود، پس هر نسخه چند بایت جا می‌گیرد. رنگ اول هر پالت رنگ پس‌زمینه است.

## انتقال به ESP

همهٔ پروژه‌های ذخیره‌شده را در یک پوشه بگذار و بسته را بساز:

```bash
node tools/epsc.mjs examples -o firmware/epsilon_firmware/animations_data.h
```

بعد `firmware/epsilon_firmware/epsilon_firmware.ino` را آپلود کن.

- برد: ESP32C6 Dev Module با USB CDC On Boot فعال
- کتابخانه‌ها: LovyanGFX و Adafruit MPU6050
- اگر بسته از حدود ۹۰۰ کیلوبایت بزرگ‌تر شد، Partition Scheme را Huge APP بگذار.

دستورهای Serial Monitor با سرعت 115200:

| کلید | کار |
|---|---|
| n | انیمیشن بعدی |
| v | نسخهٔ رنگی بعدی |
| d | مکعب دیباگ و نمایش FPS |
| m | چاپ دادهٔ MPU |

## تنظیم روی سخت‌افزار

- اگر تصویر در جهت اشتباه حرکت کرد، علامت `AXIS_X`، `AXIS_Y` یا `AXIS_Z` را در فایل `.ino` عوض کن.
- مقدارهای فنر را در ادیتور امتحان کن و در `SPRING_K`، `SPRING_C` و `SPRING_GAIN` کپی کن.
- اگر سیم‌کشی پایدار بود، `SPI_HZ` را روی 80000000 امتحان کن.

## تست‌ها

```bash
node --test tests/
```

تست تطبیق C++ و JS به یک کامپایلر C++ نیاز دارد و بدون آن رد می‌شود. مسیر کامپایلر را در متغیر `EPS_CXX` بگذار، مثلاً `g++` یا `zig c++`.

اگر `scr/player.js` را عوض کردی، همان تغییر را در `firmware/epsilon_firmware/epsilon_player.h` هم بده. این تست اختلاف آن دو را نشان می‌دهد.
